# ThermoWatch

**ThermoWatch** is a Unity-based 3D data-centre visualization built for the CGVR course project. It renders a clean, interactive data-centre facility using primitive geometry only — no imported models required:

- **Data hall** — 4 rows × 8 server racks on a 600 mm raised-floor tile grid, with perforated cold-aisle supply tiles
- **Cooling stations** — 4 CRAC units with dark charcoal bodies and blue lattice discharge tops
- **Power infrastructure** — UPS-A / UPS-B, battery cabinet (BATT-A), LV switchgear, row-end PDUs and network cabinets, overhead cable trays
- **Safety & services** — FM-200 fire-suppression cylinders, chilled-water (blue) / fire-suppression (red) process pipework, catwalk railings, overhead light strips
- **UI** — a **LABELS: ON/OFF** toggle at the top of the screen (or press **L**) to show/hide all billboard labels

Everything in the scene is regenerated by a single editor script (`DataCenterGuard → Rebuild Data Center Scene`), so the layout is always reproducible from code.

## How to clone and open the project

1. **Install Unity Hub** → <https://unity.com/download>, then install **Unity 6000.6.4f1** through
   *Installs → Install Editor* (any module set is fine; Linux editor needs no extra modules for this project).

2. **Clone the repository:**

   ```bash
   git clone https://github.com/GowdaVarun/ThermoWatch.git
   cd ThermoWatch
   ```

   > Tip: if you prefer SSH, use `git clone git@github.com:GowdaVarun/ThermoWatch.git`.

3. **Open the project in Unity Hub:**
   *Projects → Open → select the cloned folder* (the folder that contains `Assets/`).
   Unity Hub will detect version 6000.6.4f1 and offer to open it with that editor — click **Open**.

4. **First import:** Unity will import all packages and compile scripts (1–3 minutes).
   The `Library/` folder is created locally and is **never** committed, so every collaborator gets a fresh import — that is expected and correct.

5. **Open the main scene:**
   In the Project window navigate to `Assets/Scenes/DataCenterGuard.unity` and double-click it.

6. **Run it:** press **▶ Play** (top-center of the editor).
   - Right-mouse drag → orbit the camera
   - Mouse scroll → zoom
   - **R** → reset the camera view
   - Top of the screen → **LABELS: ON/OFF** button (or press **L**)

7. *(Optional)* To regenerate the whole facility from code, use the editor menu
   **DataCenterGuard → Rebuild Data Center Scene** (exit Play Mode first).

## Committing your changes (for collaborators)

Unity projects have two golden rules:

1. **Never commit `Library/`, `Temp/`, `Logs/`, `UserSettings/`** — the repo's `.gitignore` already blocks them.
2. **Always commit the matching `.meta` file next to every new asset** — Unity's asset GUIDs live there; losing a `.meta` breaks references for everyone else.

### Everyday workflow

```bash
# 1. Pull the latest work before you start editing
git pull --rebase

# 2. Check what changed (Unity scenes/.meta files change often)
git status
git diff --stat

# 3. Stage your work — add specific files rather than blindly adding everything
git add Assets/Scripts/UI/MyNewScript.cs Assets/Scripts/UI/MyNewScript.cs.meta

# 4. Commit with a clear, present-tense message
git commit -m "Add hotspot overlay to rack visuals"

# 5. Push to GitHub
git push origin main

# 6. If others pushed while you worked, rebase and push again
git pull --rebase
git push origin main
```

### Branching (recommended for anything non-trivial)

```bash
git checkout -b feature/label-toggle     # create + switch to a feature branch
# ... make changes, then:
git add <files>
git commit -m "Improve label toggle layout"
git push -u origin feature/label-toggle  # first push sets the upstream
# open a Pull Request on GitHub and get the change reviewed before merging
```

### Handy to know

- **Scene conflicts:** only one person should edit `DataCenterGuard.unity` at a time. Prefer editing scripts (like `DataCenterSceneBuilder.cs`) over hand-editing the scene.
- **Large binary assets:** keep them minimal. If one is unavoidable, commit it with Git LFS: `git lfs track "*.psd"`.
- **Don't rename assets from your OS file manager** — rename inside the Unity editor so the `.meta` file stays in sync.
